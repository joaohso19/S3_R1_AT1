### 📑 Estrutura e Elementos do Projeto

| Arquivo / Elemento | Tipo | O que foi feito / Finalidade | Por que foi utilizado? |
| :--- | :--- | :--- | :--- |
| **`<!DOCTYPE html>`** | Tag HTML | Declaração do tipo de documento | Informa ao navegador que o arquivo está escrito no padrão HTML5. |
| **`<html lang="pt-br">`** | Tag HTML | Tag raiz da página com idioma | Define o idioma principal da página como português do Brasil, auxiliando SEO e leitores de tela. |
| **`<head>`** | Tag HTML | Cabeçalho do documento | Agrupa dados técnicos e metadados que não aparecem visivelmente no corpo do site. |
| **`<meta charset="UTF-8">`** | Tag HTML | Configuração de codificação de caracteres | Garante que acentos e caracteres especiais (como `~`, `ç`, `á`) sejam exibidos corretamente. |
| **`<meta viewport>`** | Tag HTML | Configuração de responsividade | Ajusta a largura e a escala inicial da página para telas de dispositivos móveis. |
| **`<title>`** | Tag HTML | Título da página | Define o nome da aba no navegador (ex: *NexT SysteM*). |
| **`<link rel="stylesheet">`** | Tag HTML | Vínculo com arquivo externo | Conecta o arquivo CSS externo (`style.css`) às páginas HTML. |
| **`<style>`** | Tag HTML | Bloco de CSS interno | Permite aplicar estilos CSS específicos diretamente dentro do arquivo HTML. |
| **`<body>`** | Tag HTML | Corpo do documento | Contém todo o conteúdo visível da página (textos, imagens, botões). |
| **`<h1>` e `<h2>`** | Tag HTML | Títulos e cabeçalhos | Define os títulos principais e secundários, estabelecendo hierarquia visual e importância do texto. |
| **`<p>`** | Tag HTML | Parágrafo de texto | Agrupa blocos de texto explicativos ou informativos na tela. |
| **`<br>`** | Tag HTML | Quebra de linha | Força uma quebra de linha manual dentro do mesmo parágrafo sem criar espaço extra. |
| **`<img>`** | Tag HTML | Inserção de imagem | Exibe imagens nas páginas (logotipo, imagens de produtos), usando atributos como `src`, `alt` e `width`. |
| **`<div>`** | Tag HTML | Container/Divisória | Funciona como um bloco organizador para agrupar elementos (ex: agrupar textos ou os botões de navegação). |
| **`<a>`** | Tag HTML | Link de hipertexto | Torna o elemento clicável e redireciona o usuário para outra página usando o atributo `href`. |
| **`<button>`** | Tag HTML | Botão interativo | Cria um elemento clicável no qual o usuário pode interagir para realizar uma ação ou navegação. |
| **`display: flex` / `column`**| Propriedade CSS | Layout em Flexbox | Organiza os botões em coluna vertical com espaçamento uniforme (`gap: 10px`). |
| **`:hover` / `:active`** | Pseudo-classe CSS | Efeitos de interação nos botões | Aplica animações ao passar o mouse (elevação, alteração de cor, brilho) e ao clicar (efeito de afundamento). |
| **`index.html`** | Página HTML | Página Inicial (*Home*) | Apresenta a empresa, mensagem de boas-vindas e o menu principal com os botões de navegação. |
| **`catalogo.html`** | Página HTML | Página de Produtos | Exibe o título da seção e imagens do catálogo de produtos disponíveis. |
| **`biografia.html`** | Página HTML | Página "Quem Somos?" | Apresenta a história, localização e ramo de atuação da empresa no comércio eletrônico. |
| **`suporte.html`** | Página HTML | Página de Suporte | Fornece as informações de contato com o atendimento (WhatsApp). |
